# FILMKOREA

Отдельный плагин для Lampa с каталогом **только южнокорейских полнометражных фильмов**.

## Подключение в Lampa

1. Откройте настройки Lampa → Расширения.
2. Выберите добавление расширения по ссылке.
3. Вставьте адрес:

`https://raw.githubusercontent.com/SanFlauerXX/FILMKOREA/main/FILMKOREA-1.2.0.js`

4. Сохраните и перезапустите Lampa.

Название плагина: **FILMKOREA**. Текущая версия: **1.2.0**.

## Каталог

- Новинки
- Популярные фильмы
- Лучшие по рейтингу
- Скоро выйдут
- Боевики
- Криминал
- Триллеры
- Ужасы
- Драмы
- Комедии
- Мелодрамы
- Детективы
- Фантастика
- Приключения
- Поиск корейских фильмов

Данные загружаются из TMDB при открытии категорий. Фильтр ограничивает каталог оригинальным языком `ko` и страной производства `KR`; сериалы не запрашиваются.
